# MaynorAI 文章同步助手可以把一篇文章同步到 23 个平台的草稿箱

MaynorAI 文章同步助手可以把一篇文章同步到 23 个平台的草稿箱。默认只创建或更新草稿，不会直接发布；只有你主动打开「同步后直接发布」时，才会尝试发布。

工作台地址：[https://editor.maynor1024.live/](https://editor.maynor1024.live/)  
产品介绍：[https://product.maynor1024.live/](https://product.maynor1024.live/)

![产品介绍页](https://upload.maynor1024.live/file/1795057062551_08-product-hero.png)

写作、保存草稿、同步到各平台草稿箱是免费的。需要付费的是「AI 润色」「文章插图」和「做封面」。

## 1. 安装浏览器扩展

同步依赖本机浏览器扩展，账号和 Cookie 只留在你自己的浏览器里，不会出现在网页上。

打开工作台后，点顶部的「扩展连接」，按侧栏说明安装：

1. 下载并解压安装包。
2. 在 Chrome 打开扩展管理页，或在 Edge 打开扩展管理页。
3. 打开右上角「开发人员模式」。
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹（里面要有 `manifest.json`）。
5. 打开扩展弹窗，保存自动生成的连接密钥。这一步只需做一次；以后更新只需在扩展管理页点「重新加载」，不必重新选文件夹。

Edge 也可以先在商店安装。商店审核通过后，也可以改从 Chrome 应用商店安装。

安装并连接成功后，顶部会显示已连接和扩展版本。如果仍提示「未检测到扩展」，点「重新检测」，或刷新页面。

![扩展连接与安装说明](https://upload.maynor1024.live/file/1795073604233_07-扩展连接.gif)

## 2. 登录，用云端文章夹

未登录时，草稿只保存在当前浏览器。登录后，左侧「云端文章夹」会加载你的云端文章，换设备也能继续写。

点左侧标题「云端文章夹」可以刷新列表。

![登录后的工作台和云端文章夹](https://upload.maynor1024.live/file/1795073608644_01-云端文章夹.gif)

## 3. 写作、预览和保存

中间是编辑区。可以用 Markdown 写作，随时切到「预览」看排版效果。顶部工具栏提供标题、列表、链接、保存、历史版本等常用操作。

写完后点右下角「保存草稿」。未登录时草稿只在本机；登录后会同步到云端文章夹。

![写作与预览](https://upload.maynor1024.live/file/1795073609504_02-写作预览保存.gif)

## 4. 用 AI 润色正文

登录后，点工具栏「AI 工具」里的「AI 润色」（窗口较宽时也可能直接显示在工具栏上）。先选模型，再写一句要求（例如「语气更口语，保留我的小节结构和表格」），然后点「开始润色」。

当前可选模型为 Claude Opus 5.5、GPT-6.2 Sol、Gemini 4 Hydrogen、Grok 4.7，均为专业版模型。润色结果会一边生成一边显示，不用干等整篇完成。

写作本身不扣积分；只有开始润色才会消耗次数或积分。

![AI 润色面板](https://upload.maynor1024.live/file/1795073611381_03-AI润色.gif)

## 5. 做封面和文章插图

「AI 工具」里还有「做封面」和「文章插图」。

做封面时，可填写封面文案，也可上传参考图，再点「生成 16:9 封面」。文章插图则按正文需要插入配图。这两项会消耗套餐图额度，没有套餐时需要先开通。

![做封面](https://upload.maynor1024.live/file/1795073615885_04-做封面.gif)

## 6. 同步到各平台草稿箱

扩展已连接、文章已保存后，点右下角「同步到草稿箱」。

在弹窗里勾选要同步的平台和账号，确认后再点「创建同步任务」。默认不会直接发布。如果某个平台显示「未能确认」，先回到扩展里登录该平台，再点「重新检测」。

GitHub 需要在扩展中添加 Token。X 长文同步到 [X Articles](https://x.com/compose/articles)，需要付费的 X 方案；扩展只会尽量保存草稿，不会替你点「发布」。

不需要同步时，点「关闭」即可，不会创建任务。

![同步到草稿箱](https://upload.maynor1024.live/file/1795073622341_05-同步到草稿箱.gif)

## 7. 查看同步历史

点工具栏「同步任务」，打开侧栏「历史任务」，可以查看最近的同步结果。如果还没有创建过任务，这里会显示「暂无任务」。

![历史任务](https://upload.maynor1024.live/file/1795073619358_06-历史任务.gif)
